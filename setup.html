Tesla Watch · Cloud-Einrichtung

Optional. Damit steuerst du dein Auto auch über das Internet, mit deinem eigenen Tesla-Developer-Konto. Alles bleibt bei dir: Diese Seite speichert nichts, die Daten gehen am Ende nur an deine Uhr.

Diese Seite wurde nicht von der Uhr geöffnet. Bitte auf der Uhr Einstellungen → Cloud → Am Handy einrichten antippen, dann öffnet sie sich hier automatisch mit den Daten deiner Uhr.

1. Public Key deiner Uhr veröffentlichen

Tesla verlangt, dass der öffentliche Schlüssel der Uhr unter einer Domain erreichbar ist. Kostenlos geht das mit GitHub Pages.

Deine Domain ist dann <name>.github.io.

a) Repository „<name>.github.io“ anlegen (öffentlich) b) Datei „.nojekyll“ anlegen c) Public Key als Datei anlegen

Bei b) und c) öffnet sich GitHub mit vorausgefülltem Inhalt – nur unten auf „Commit changes“ tippen. Nach 1–2 Minuten ist der Key online.

2. Tesla-Developer-App anlegen

Auf developer.tesla.com anmelden → „Create new app“ und eintragen:

  • Allowed Origin(s): https://<name>.github.io
  • Allowed Redirect URI(s):
  • Scopes: vehicle_device_data, vehicle_cmds, vehicle_charging_cmds

Unter „Billing“ eine Zahlungsmethode hinterlegen (Tesla schenkt 10 $ Guthaben pro Monat, das reicht privat locker). Danach Client ID und Client Secret kopieren.

developer.tesla.com öffnen

3. Zugangsdaten an die Uhr senden

Die Uhr registriert danach die Domain bei Tesla, öffnet den Link zum Koppeln des Virtual Key auf diesem Handy und meldet dich an.
