Tesla Watch · Cloud-Einrichtung

Optional. Damit steuerst du dein Auto auch über das Internet, mit deinem eigenen Tesla-Developer-Konto. Alles bleibt bei dir: Diese Seite hat keinen Server, die Daten gehen am Ende nur an deine Uhr.

Diese Seite wurde nicht von der Uhr geöffnet. Bitte auf der Uhr Einstellungen → Cloud → Am Handy einrichten antippen, dann öffnet sie sich hier automatisch mit den Daten deiner Uhr.

1. Public Key deiner Uhr veröffentlichen

Tesla verlangt, dass der öffentliche Schlüssel der Uhr unter einer Domain erreichbar ist. Kostenlos geht das mit GitHub Pages. Gib nur deinen Benutzernamen ein, die Seite erkennt selbst, was noch fehlt.

  • Datei .nojekyll
  • Public Key der Uhr
  • Online erreichbar

Noch schneller: alles automatisch per GitHub-Token

Ein Tipp erzeugt einen Token, danach legt diese Seite Repository, .nojekyll und Key selbst an. Der Token bleibt in diesem Browser-Tab und geht nur an api.github.com.

a) Token erzeugen (unten „Generate token“, dann kopieren)

Key woanders hosten (eigene Domain)

Lege den Key unter /.well-known/appspecific/com.tesla.3p.public-key.pem ab und trage die Domain in Schritt 3 ein.

2. Tesla-Developer-App anlegen

Auf developer.tesla.com anmelden → „Create new app“. Diese Werte antippen zum Kopieren:

Vehicle Information · Vehicle Commands · Vehicle Charging Management

(vehicle_device_data, vehicle_cmds, vehicle_charging_cmds)

Unter „Billing“ eine Zahlungsmethode hinterlegen (Tesla schenkt 10 $ Guthaben pro Monat, das reicht privat locker). Danach Client ID und Client Secret kopieren.

developer.tesla.com öffnen

3. Zugangsdaten an die Uhr senden

Region und Domain

Der Key ist noch nicht online. Bitte erst Schritt 1 abschließen, sonst lehnt Tesla die Registrierung ab.

Die Uhr registriert danach die Domain bei Tesla, öffnet den Link zum Koppeln des Virtual Key auf diesem Handy und meldet dich an.
